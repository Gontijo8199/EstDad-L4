# Sistema de Autocomplete de Jogos com Trie

## Alunos

- Rafael Gontijo Ferreira
- Rudá Dantas Ruoso Brandão

## Compilação

#### Pré-requisitos

- g++ 
- make

#### Compilar

```bash
make
```

#### Executar

```bash
./bins/app k "prefixo"
```

Exemplo:

```bash
./bins/app 3 ha
./bins/app 3 "half l" # Caso o prefixo possua espaços
```

#### Limpar

```bash
make clean
```
